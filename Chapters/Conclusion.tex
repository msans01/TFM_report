\subsection{Further Work}



\begin{itemize}
    \item Allow the  EMT simulation to handle events on the grid.
    \item Implement parallelization of the region BlockSolvers to improve calculation time.
    \item Include more device models in the Symbolic-Numeric framework to increase the versatility of the EMT simulation.
    \item Create the GUI interface for the EMT simulation setup and results visualization.
    \item Perform extensive testing and validation of the EMT simulation with a variety of test systems and scenarios.
    \item Optimize the code for performance improvements, including memory management and computational efficiency.
    \item Change the line model to a frequency-dependent one to improve accuracy.
    \item Implement a more robust transformer model including saturation effects.
    \item Incorporate renewable energy source models, such as wind solar and converters, into the EMT simulation framework.

\end{itemize}
